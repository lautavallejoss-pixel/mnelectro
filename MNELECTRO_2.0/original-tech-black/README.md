# MNELECTRO — TECH BLACK

Prototipo front-end de una tienda online premium, creado como propuesta visual para presentar al propietario de MNELECTRO.

## Cómo abrir
1. Descomprimí `MNELECTRO_Tech_Black.zip`.
2. Abrí la carpeta en Acode, Visual Studio Code o cualquier editor.
3. Abrí `index.html` en un navegador. Para una mejor experiencia en escritorio, también podés usar la extensión Live Server de VS Code.

## Archivos
- `index.html`: estructura completa de la tienda.
- `styles.css`: identidad visual, responsive y animaciones.
- `script.js`: interacciones de demostración.

## Interacciones incluidas
- Navegación adaptable a móviles.
- Buscador y filtros de productos.
- Animaciones de aparición al desplazarse (scroll reveal).
- Carrito lateral con cantidades, subtotal y eliminación.
- Vista rápida de productos.
- Favoritos de demostración.
- Formulario visual de novedades.
- Mensajes toast y cierre con tecla Escape.

## Identidad visual
- Negro: `#0B0B0F`
- Azul eléctrico: `#3382F6`
- Grafito: `#1E293B`
- Blanco frío: `#F8FAFC`
- Tipografías: Manrope + DM Sans.

## Importante antes de presentarlo
Este es un prototipo visual, no una tienda conectada a ventas reales. Los productos, precios, promociones, imágenes y textos son de ejemplo. Las imágenes se cargan desde URLs externas de Unsplash, por lo que necesitan conexión a internet. No procesa pagos, no consulta stock, no guarda pedidos y no envía formularios a un servidor.

Antes de publicarlo o integrarlo:
- Reemplazar productos, precios, imágenes, categorías y datos de contacto por información autorizada y real.
- Confirmar las condiciones de envío, medios de pago y garantías con el propietario.
- Conectar el carrito y el checkout a la plataforma de comercio electrónico que utilice el negocio.
- Confirmar permisos para usar marca, logotipo, fotografías y contenidos.
- No presentar reseñas ficticias como testimonios reales.

## Siguiente etapa sugerida
Adaptar el diseño a la plataforma actual de MNELECTRO (por ejemplo, Tiendanube, WooCommerce u otra). Mantener el catálogo y las operaciones reales del negocio; no reemplazar una tienda productiva sin autorización.
